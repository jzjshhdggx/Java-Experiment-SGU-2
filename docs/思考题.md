# 实验二 思考题

## 1. 使用变量之前是不是都要先声明变量？是不是都要先赋值？为什么？

使用变量之前必须先声明，以确定变量的名称和数据类型，编译器据此分配存储空间并进行类型检查。

- 局部变量：声明后还必须显式赋值才能使用，否则编译时会报“可能尚未初始化”的错误。
- 成员变量和静态变量：有默认初值（如 `int` 为 0、`boolean` 为 `false`、引用类型为 `null`），可以先声明后赋值。

因此，声明是必需的；赋值则取决于变量的种类和使用场景。

## 2. 什么是构造方法？

构造方法是类中一种特殊的方法，名称与类名相同，没有返回值类型（也不写 `void`）。它不能像普通方法那样直接调用，只能通过 `new` 运算符在创建对象时调用，用于初始化对象的成员变量。

构造方法可以重载，一个类可以有多个参数不同的构造方法；如果没有定义构造方法，编译器会提供一个默认的无参构造方法。

## 3. 程序中有多个类时如何确定源程序文件的名称？

如果源程序中有一个 `public` 类，源文件名必须与该 `public` 类的类名完全相同，扩展名为 `.java`；如果没有任何 `public` 类，源文件名可以与其中任意一个类名相同。

编译后每个类都会生成对应的 `.class` 文件，文件名与类名相同。

## 4. 类的继承和多态有什么作用？在使用上应该注意什么问题？

作用：

- 继承可以提高代码的复用性，子类可以沿用父类的成员并在此基础上扩展。
- 多态可以让同一方法名在不同对象上表现出不同的行为，提高程序的灵活性和可扩展性。

注意事项：

- 子类不能直接访问父类的 `private` 成员。
- 构造方法不能被继承。
- 方法覆盖必须保持方法名、参数列表相同，返回值类型兼容。
- 使用父类引用指向子类对象时，只能调用父类中声明的方法，实际执行的是子类重写的方法。
- 静态方法不能被覆盖，只能被隐藏。
